# Contributing to `the-price-of-a-life`

This repo is an open invitation: **fork your own life.**

## How to contribute

**File an issue — what do you need?**
Describe a problem you're facing. Someone out there has a commit that solves it, from a life you'd never expect. Label it `help-wanted`.

**Submit a PR — what do you know?**
Add your fork to [`trades/`](trades/). One file per life, named for the trade:
`trades/<your-trade>.md`. Each file follows the same shape:

```md
# The <Trade>

## The repo
<Who this person is. Two or three lines. Real people preferred; composites clearly labeled.>

## The commits
<The lived experience — the specific scars, seasons, and 3 AM moments that built the ability.>

## The fork
<Where this ability landed in an unexpected domain. What problem it solved. What it was worth.>

## The lesson
<One line. What this fork proves about the price of a life.>
```

**Improve a fork.**
Someone's fork missing the real lesson? Open a PR against it. That's the point — the commons gets smarter with every merge.

## Ground rules

- Real people, real trades. If it's a composite, say so.
- No invented quotes, no invented salaries, no invented outcomes. If you don't know what it was worth, say what changed instead.
- Be kind in review. Every repo here took a lifetime to build.
- MIT licensed, like everything here. Your contribution is a gift to the commons.

## The maintainers are everyone.

Commit often. Document your scars. Make yourself forkable.
